Plan a two-point offset

  1. Choose inches, feet and inches, or millimeters.
  2. Enter the measured offset height, equal bend angle and first theoretical mark distance from the cut end.
  3. Choose Calculate marks. M1 and M2 are both measured from the same cut end, away from that end.
  4. Check the result, tool instructions and reference marks before marking the pipe. Save the calculation to Library if needed.

Understand the result

Results use ideal point-bend geometry. Theoretical shrink is shown separately and is not automatically added to the first mark. A common tool correction shifts both marks equally; it does not calculate take-up, springback or finite-radius accuracy. Optional radius parameters check clearance feasibility only. Each displayed dimension is rounded independently.

Input formats

Inches accept values such as 6, 3/4 or 6 1/2. Feet-and-inches accepts 2' 3 1/2". Millimeters use decimals. Angles range from 10° to 60°. Correct invalid inputs before changing units.

Local records

History, favorites, draft inputs and tool configurations are stored on the device. If a saved workspace cannot be read, the app keeps the original file and reports the error. Use Field guide → Export original workspace when available before resetting. Reset all local data removes the local workspace; it does not remove an Apple purchase or copies in device backups.
